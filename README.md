# Paython Mini Utils 🐍

A small Python learning project with reusable utility functions, tests, and a simple CLI.

## Project structure
- `paython_utils/` → Python package with utility modules
- `tests/` → pytest tests (includes `conftest.py` to help imports)
- `main.py` → demo script that runs a few examples

## Features
### String utilities
- `reverse_string(text)` → reverse a string
- `count_vowels(text)` → count vowels in a string

### Math utilities
- `add(a, b)` → add two numbers
- `is_even(n)` → check if a number is even

## Run the demo

python main.py
